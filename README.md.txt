# 🌍 Language Translation Tool

An interactive **Language Translation Tool** built with **Python** and **Streamlit** that lets users translate text between multiple languages instantly.

---

## ✨ Features
✅ Enter any text and translate it instantly  
✅ Choose **Source** & **Target** languages  
✅ Clean, beginner-friendly UI  
✅ Powered by **Deep Translator API** for reliable translations  

---

## 🛠 Tech Stack
- **Python 3**
- **Streamlit** (for UI)
- **deep-translator** (for translation)
